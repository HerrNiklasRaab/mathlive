# Built package

This branch holds the built npm package of MathLive (the `dist/` output of
`npm run build production`) from commit `25c71ab1` on the `fix/german-mac-caret`
branch (https://github.com/arnog/mathlive/pull/3137), so that it can be installed
with `npm install github:HerrNiklasRaab/mathlive#dist/german-mac-caret` until the
fix is released. It is not a source branch.
